# Ambiente: Pessoal
verificado em: 2026-10-20
## TL;DR
- Stack variada (C#, React, JavaScript e outras). O usuario projeta a arquitetura.
- Decisoes de cada projeto ficam em `ambientes/pessoal/projetos/<projeto>.md` (modelo: `_modelo.md`).
## Stack
- Varia por projeto; veja o arquivo do projeto e a nota de cada tecnologia em `conhecimento/`.
## Arquitetura
1. O usuario e o projetista: proponha opcoes com pros e contras e espere a decisao. Nao escolha framework, camadas ou padroes por conta propria (regra geral 7).
2. Em projeto ja existente, siga o que esta no arquivo do projeto e no codigo.
3. Decisao tomada no chat (stack, arquitetura, testes) deve ser registrada no arquivo do projeto, com aviso ao usuario.
## Testes
1. Framework e convencao de nomes de teste sao definidos por projeto (arquivo do projeto). Sem definicao, pergunte.
## Inicio do chat
1. Pergunte o nome do projeto e leia `ambientes/pessoal/projetos/<projeto>.md`.
2. Se o arquivo nao existir, ofereca criar a partir de `_modelo.md`.
## Notas que se aplicam
- conhecimento/arquitetura-e-escopo.md (regras de escopo; criar camadas e permitido quando o usuario decidir)
- Notas das tecnologias usadas no projeto (ver `conhecimento/indice.md`)
